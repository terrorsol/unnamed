# UNNAMED — beta (real money, mainnet)

Non-custodial Solana memecoin terminal + launchpad. Every button is a real transaction signed by the user's wallet.

## What's live
| Feature | How |
|---|---|
| Wallet connect | Phantom / Solflare / Backpack via wallet-adapter |
| Board, prices, charts | DexScreener public API + embedded chart |
| New launches + curve trades | pump.fun live stream via PumpPortal websocket |
| Buy / sell (bonding curve) | PumpPortal `trade-local` → user signs → RPC send |
| Buy / sell (graduated) | Jupiter lite-api quote + swap (fallback PumpPortal auto) |
| Launch a coin | metadata → pump.fun IPFS → PumpPortal create tx (mint keypair + wallet co-sign) |
| Portfolio | on-chain balances (SPL + Token-2022), cost basis + hold clock kept in-browser |
| Protocol preview | vault / flip-fee / desk / redeem math computed live, labeled PREVIEW (not enforced on-chain yet) |

## Run
```
npm install
npm run dev        # http://localhost:5173
npm test           # protocol unit tests
npm run build      # → dist/
```
Set a fast RPC (Helius/Triton/QuickNode) in Settings — the public endpoint rate-limits.

## Deploy
Static site. Any of:

## In-app wallet (1-click trading)
Default wallet is a browser-side keypair encrypted with a user password (PBKDF2-310k → AES-GCM, localStorage). Deposit from Phantom, trade with no popups, withdraw anytime, export/import key. Phantom/Solflare/Backpack remain available under "Phantom / extension".

## Desk + vault (live, bot-run)
See `server/README.md`. Desk = non-custodial block bids matched by our server, settled by a two-signer tx. Vault = our bot running the market-maker rules per coin (custodial in beta).

## Import a coin · activate a vault
Any coin with a market: 15 SOL (10 → treasury, 5 → chest), one signature, verified on-chain by the server before arming. Owner can deposit tokens ("vault your bag"); anyone can top up the chest. Trims capped 2%/trim, 5%/day, 10% of 1h volume.

## Market-maker mode
Per-vault mode `mm` (default) or `floor`. MM counters buys when price is stretched over 30-min VWAP: capture = clamp(10% + stretch×40%, 0, 30%) × mcap tier (×0.5 <$100K, ×1 <$1M, ×0.75 above) × ±20% random, trigger rate 40–70% by buys/min, min buy 0.5 SOL, ≤15% of 1h volume, ≤10% of position/day, ≤5% per capture. Never on dips. Captured SOL → chest → 60% desk bid at −4%, 40% defense in three tranches (−20/−35/−50% from 15-min high). Dev ceiling 5–30%. Everything shows live on the coin page (capture now, stretch, trigger, tier) with a scorecard (captured, redeployed, bought off-chart, floor).

## Backtest / Simulate
`app/src/lib/sim.ts` — constant-product pool, scripted + seeded random flow (chop → pump → dump → recover), 1.5% swap fees, the vault's real rules. `npm test` in `app/` asserts: MM lowers drawdown, does not cap the pump, is profitable, keeps holders better off; 5% chest is cosmetic; <10 tx/hr. The Simulate page runs it in-browser with sliders.

## Signals
`app/src/lib/signal.ts` labels every coin RUNNER / HEALTHY / COOLING / CRASHING / BUNDLED / RUG RISK / DEAD from live structure (1h/6h/5m moves, buy:sell, turnover vs mcap, liquidity vs mcap, age, holder concentration, authorities), always with reasons. Tested on synthetic runner / rug / bundle / crash / dead shapes generated by the simulator (`test/signal.test.mjs`).

## Chart + routing
Own candlestick chart (lightweight-charts) from GeckoTerminal OHLCV with live ticks from our streams; vault captures (C), dip buys (D), desk fills (OTC), redeems (R), the redeem floor and your TP/SL drawn on it; DexScreener embed as fallback. Sends: Helius priority-fee estimate (High), Jito tip on Jupiter swaps, skip-preflight + 2s rebroadcast until confirmed.
